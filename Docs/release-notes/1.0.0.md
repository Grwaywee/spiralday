Spiralday 첫 버전이에요. 창 하나가 곧 종이 한 장인 macOS 플래너.

- 일간: 10분 단위 종이 플래너 형식 — DATE · D-DAY · COMMENT · TOTAL TIME · TASKS · MEMO · TIMETABLE
- 주간: MY GOAL, 주간 회고, 월–일 7칸 (할 일 · 타임테이블 · 하루 합계)
- 홈: 이번 주·이번 달 시간, 연속 기록, 완료율, 최근 12주, 형광펜별 시간, 최근 35일 달력
- 진짜 종이처럼 넘어가는 페이지 (모서리 드래그, 트랙패드 스와이프, ← →)
- 형광펜 타임테이블, 손글씨 메모, 🍴 밥시간 화살표
- ○ △ × → 체크, 끝낸 일에만 형광펜, 같은 형광펜끼리 모으기
- 날마다 고르는 컬러 컨셉, D-day 두 개
- 플래너 여러 권 (시작일 · 종료일), 첫 실행 튜토리얼
- PDF 로 뽑기: 일간 A4 반쪽 두 장씩 (자르면 실물 크기) · A4 세로, 주간 · 홈 A4 가로
- 자동 업데이트

설치: zip 을 풀어 Spiralday.app 을 응용 프로그램 폴더로 옮기고, 처음 한 번은 오른쪽 클릭 → 열기.
