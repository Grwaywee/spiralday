어떤 Mac 에서 얼마나 쓰이는지 알기 위해 익명 사용 통계를 더한 업데이트예요.

- 익명 사용 통계: 하루 한 번 앱 버전 · macOS 버전 · 칩 종류 · 언어와 무작위 설치 번호만 보내요. 플래너 기록은 보내지 않고, 설정 → 데이터에서 끌 수 있어요
- 개인정보 처리방침 페이지를 만들었어요 (spiralday.com/privacy.html, 메뉴 도움말 → 개인정보 처리방침)

설치: `Spiralday.dmg` 를 열고 Spiralday 를 Applications 폴더로 끌어다 놓으면 끝. 이미 쓰고 있다면 메뉴 Spiralday → 업데이트 확인… 으로 받을 수 있어요.
