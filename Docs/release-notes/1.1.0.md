내 기기끼리 플래너를 맞추는 **Spiralday Sync** 가 Mac 에도 들어왔어요. 기본은 꺼져 있고, 켜기 전에는 예전과 똑같아요.

- 설정 → 동기화에서 켜요. 처음 기기에서 ‘이 Mac 에서 시작하기’ → 복구 코드를 적어 두고 (복사 · 텍스트 파일 · 인쇄 → 두 묶음을 다시 입력해 확인), 다른 기기는 ‘기기 추가’의 QR 이나 8자리 코드로 들어와요. 새 기기 화면의 숫자 4자리를 이 Mac 에 입력해야 연결돼요
- 이미 동기화를 쓰는 기기(Windows · iPhone · iPad)가 있으면 ‘다른 기기에 합류하기’에 그 기기의 8자리 코드나 ‘연결 글’을 넣어요. 합치기 직전에 이 Mac 의 플래너를 저절로 백업해 둬요 (설정 → 데이터 → 백업 가져오기로 꺼내 볼 수 있어요)
- 종단간 암호화: 기록은 이 Mac 에서 암호화된 뒤에 보내져요. 열쇠는 내 기기에만 있어서 서버도, Spiralday 회사도 플래너를 읽을 수 없어요. 계정 · 이메일 · 비밀번호가 필요 없어요
- 겹쳐 써도 괜찮아요: 여러 기기에서 고쳐도 칸마다 마지막에 쓴 것이 남고, 지운 것은 되살아나지 않아요. 인터넷이 없어도 쓰다가 연결되면 맞춰요. 쓰는 중인 칸은 다른 기기의 편집이 들어와도 글 · 커서가 흔들리지 않고, ⌘Z 가 다른 기기의 글을 지우지 않아요
- 하루 · 한 주의 이전 버전(30일): 일간 · 주간 장을 보면서 플래너 메뉴 → ‘이 날의 이전 버전…’ · ‘이 주의 이전 버전…’, 또는 설정 → 동기화 → 이전 버전 보기
- 기기 목록 · 이름 바꾸기 · 빼기, 복구 코드 새로 만들기, 이 Mac 에서 끄기, 그룹 지우기(서버의 사본을 바로 지워요)
- 팔레트의 설정 단추 귀퉁이에 동기화 상태가 작게 보여요 (동기화를 켰을 때만). 손볼 것이 있으면 그 단추가 설정 → 동기화로 바로 열어요. 플래너 메뉴에 ‘지금 맞추기’(⇧⌘S) · ‘동기화 설정…’
- 잠자기 전에 남은 편집을 올리고, 깨어나거나 네트워크가 돌아오면 바로 다시 맞춰요. 끝낼 때도 남은 편집을 올려요 (오래 기다리지 않아요)
- 다른 Mac 으로 옮겨 왔을 때(이전 지원 · Time Machine 복원): 두 Mac 이 한 기기로 붙지 않게 동기화를 멈추고 ‘이 Mac 에서 이어 쓰기’ · ‘정리하기’를 물어요
- 설정 → 데이터 → 정보에 오픈소스 고지(libsodium · swift-sodium · Sparkle)를 넣었어요

개인정보: 동기화를 켜지 않으면 아무것도 보내지 않아요. 켜면 암호화한 기록과, 맞추는 데 필요한 것(기록의 크기와 쓴 때, 기기 수 · 종류와 접속한 때)만 동기화 서버에 둬요. 자세한 내용은 [개인정보 처리방침](https://spiralday.com/privacy.html)에 새로 적었어요.

설치: `Spiralday.dmg` 를 열고 Spiralday 를 Applications 폴더로 끌어다 놓으면 끝. 이미 쓰고 있다면 메뉴 Spiralday → 업데이트 확인… 으로 받을 수 있어요.
