1.1.0 을 쓰면서 걸리던 곳을 고친 업데이트예요.

- 설정 → 형광펜에서 펜 줄을 끌어 위아래 순서를 바꿀 수 있어요. 숫자 배지와 숫자 키 1–7 도 새 순서를 따라요 (오른쪽 클릭 ‘위로 · 아래로 옮기기’도 돼요)
- 일간 · 주간 할 일 앞의 분류 칸이 잘 눌려요. 천천히 누르거나, 누르면서 조금 움직이거나, 칸 가장자리를 눌러도 형광펜 메뉴가 떠요
- 일간 COMMENT 에서 Return 을 누르면 줄이 바뀌어요 (다섯 줄까지). 쓰기를 끝낼 때는 ⌘↩ · Esc · 종이 빈 곳 클릭. 조합 중인 키는 입력기가 먼저 받아서 한글 조합 · 한자 변환(⌥↩) · 후보 고르기는 그대로 돼요. 다섯 줄보다 긴 예전 글은 다섯 줄까지 보이고 뒤는 … 로 줄여요 (글은 그대로 남아요)
- 타임테이블의 밥 동그라미 위에서 시작해도 다른 칸처럼 칠하고 지워요 (글씨 · 밥 도구도). 동그라미를 오른쪽 클릭하면 예전처럼 ‘밥시간 지우기’
- 칠한 칸을 같은 색으로 다시 칠해 지우면, 지우개처럼 그 칸의 밥시간 · 글씨 메모도 함께 지워져요 (iPhone 과 같아요). 타임테이블에서 칠하거나 지운 것은 ⌘Z 로 한 번에 하나씩 되돌릴 수 있어요
- D-day ‘새로 만들기’에 이름을 적고 [붙이기]를 누르지 않고 닫아도(바깥 클릭) 그 날에 붙어요. 한글을 조합하던 마지막 글자까지 붙고, 붙이지 않으려면 Esc 로 닫아요. 다른 앱으로 넘어가며 닫히면 붙이지 않고, 다시 열면 적던 이름이 그대로 있어요
- Spiralday 의 소스 코드 라이선스가 MIT 에서 PolyForm Noncommercial 1.0.0(소스 공개 · 비상업)으로 바뀌어, 설정 → 데이터 → 정보와 도움말 메뉴에 반영했어요. 그 전에 MIT 로 공개된 버전은 MIT 그대로예요

설치: `Spiralday.dmg` 를 열고 Spiralday 를 Applications 폴더로 끌어다 놓으면 끝. 이미 쓰고 있다면 메뉴 Spiralday → 업데이트 확인… 으로 받을 수 있어요.
