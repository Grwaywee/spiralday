도구 팔레트를 접어 두거나 원하는 쪽에 둘 수 있게 하고, 1.0.5 에서 가끔 앱이 멈추며 꺼지던 문제를 고친 업데이트예요.

- 일간 · 주간 · 홈을 바꾸거나 모니터를 연결 · 분리하는 등 화면 배치가 바뀔 때 가끔 앱이 꺼지던 문제를 고쳤어요
- 팔레트 접기: 팔레트 끝의 작은 화살표나 ⌘\ 로 접으면 종이 옆에 가느다란 손잡이만 남아요. 손잡이에는 지금 고른 도구(형광펜 색 · 지우개 · 글씨 · 밥)가 보이고, 접혀 있어도 그 도구로 타임테이블을 그대로 칠할 수 있어요
- 손잡이에 마우스를 올리면 팔레트가 펼쳐지고, 팔레트에서 벗어나면 다시 접혀요. 손잡이를 누르거나, 마우스로 펼친 채 ⌘\ 를 누르면 펼친 채로 고정돼요. 타임테이블을 칠하다 마우스를 누른 채 지나갈 때는 펼치지 않아요
- 접혀 있을 때 1–7 · E 로 도구를 바꾸면 팔레트가 잠깐 펼쳐져 무엇을 골랐는지 보여 주고 다시 접혀요
- 설정 → 팔레트의 ‘팔레트 자동으로 접기’를 켜면 늘 접힌 채로 시작해요 (처음에는 꺼져 있어서 지금처럼 펼쳐져 있어요). 접었는지 펼쳤는지는 다음에 켤 때도 그대로예요
- 팔레트 자리 고르기: 설정 → 팔레트에서 오른쪽(기본) · 왼쪽 · 위 · 아래를 그림으로 골라요. 고르면 바로 옮겨 가요
- 위 · 아래에 두면 같은 도구가 가로 한 줄로 놓이고, 형광펜은 종이 쪽으로 끝을 세워요. 스프링이 달린 쪽(일간 왼쪽, 주간 · 홈 위)에서는 스프링을 비켜 조금 더 떨어져 붙어요
- 화면에 자리가 없으면 반대쪽에 붙고, 새로 고른 쪽에 자리가 모자라면 창을 옮기거나 조금 줄여 자리를 만들어요. 초록 버튼(확대)과 쪽 바꾸기도 팔레트 자리를 비워 두고 맞춰요
- 플래너 둘러보기는 팔레트가 어느 쪽에 있든 말풍선이 그 도구를 가리키고, 접혀 있으면 둘러보는 동안만 펼쳤다가 끝나면 다시 접어요
- ‘동작 줄이기’(손쉬운 사용)를 켜 두면 팔레트를 접고 펼칠 때 움직이지 않고 바로 바뀌어요

설치: `Spiralday.dmg` 를 열고 Spiralday 를 Applications 폴더로 끌어다 놓으면 끝. 이미 쓰고 있다면 메뉴 Spiralday → 업데이트 확인… 으로 받을 수 있어요.
