D-day 를 날마다 따로 붙일 수 있게 바꾼 업데이트예요.

- D-day 가 모든 날에 똑같이 붙지 않고, 일간 페이지마다 골라 붙여요. 화요일에 붙인 D-day 가 수요일에 저절로 넘어가지 않아요
- 일간 페이지의 D-DAY 칸을 누르면 그날의 D-day 를 골라요: 저장한 D-day 에서 고르기 · 새로 만들기 · 어제와 같게 (하루 두 개까지)
- 붙인 D-day 는 그날에만 남아요. 다른 날에 다른 것을 붙이거나, 그날 것을 고치거나 떼도 다른 날은 그대로예요
- 설정 → D-day 는 ‘저장한 D-day’ 목록이 됐어요. 개수 제한 없이 저장해 두고, 목록에서 고치거나 지워도 이미 붙인 날은 바뀌지 않아요
- 팔레트의 D-day 버튼은 일간에서는 보고 있는 날, 주간 · 홈에서는 오늘에 붙여요. 홈의 D-DAY 칸은 오늘 붙인 D-day 를 보여 줘요
- 처음 열 때 원래 파일을 백업으로 남긴 뒤, 이미 쓴 날과 오늘에는 지금까지의 D-day 를 그대로 붙여 두어서 전과 똑같이 보여요

설치: `Spiralday.dmg` 를 열고 Spiralday 를 Applications 폴더로 끌어다 놓으면 끝. 이미 쓰고 있다면 메뉴 Spiralday → 업데이트 확인… 으로 받을 수 있어요.
