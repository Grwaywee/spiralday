Windows 설치 · 업데이트 안내

Spiralday for Windows 1.0 이 나왔어요. 설치 파일 안의 모든 파일에 회사 서명을 넣어서, 스마트 앱 컨트롤 때문에 설치가 막히던 문제를 고쳤어요.

  • 이미 쓰고 있다면 — 할 일이 없어요. 앱이 새 버전을 저절로 받아 두고, 종이 위에 ‘재시작해서 업데이트’를 띄워요 (업데이트)
  • 스마트 앱 컨트롤이 설치를 막았다면 — 아래 단추로 1.0 을 새로 받아 주세요. 예전에 받아 둔 설치 파일은 지워 주세요 (스마트 앱 컨트롤)
  • Edge 가 받기 전에 경고하면 — 새로 나온 파일이라 1.0 에서도 뜰 수 있어요. ‘유지’를 눌러 받으면 돼요 (Edge 경고)
  • 기록은 그대로 — 업데이트해도, 다시 설치해도, 앱을 지워도 플래너는 남아 있어요 (기록)
Windows용 무료 다운로드

Windows 10 · 11 (64비트) · 무료 · 계정 없이

1.처음 설치하기

  1. 받기 — 위 단추로 Spiralday-Setup.exe 를 받아요. Edge 가 ‘일반적으로 다운로드되지 않습니다’라고 하면 이렇게 해 주세요.
  2. 실행 — 받은 파일을 열어요. ‘Windows의 PC 보호’ 창이 뜨면 추가 정보 → 실행을 눌러요. 이때 게시자가 LeanAgileHungry . INC 이면 저희가 서명한 파일이에요 (왜 뜨나요?).
  3. 끝 — 관리자 권한 없이 내 계정에만 설치되고, 다 되면 바로 열려요.

2.이미 쓰고 있다면 — 업데이트

새 버전은 앱이 알아서 받아요. 앱을 켤 때, 그리고 켜 둔 동안 하루에 한 번 확인해요.

  1. 다 받으면 종이 위쪽에 ‘새 버전 … 을 받아 두었어요’ 카드가 떠요.
  2. 재시작해서 업데이트를 누르면 쓰던 것을 저장하고, 새 버전으로 바꾼 뒤 다시 열어요. 잠깐이면 돼요.

‘나중에’를 눌렀다면 앱을 닫을 때 조용히 설치돼요. 이때는 다시 열리지 않으니 한 번 더 열어 주세요.
앱을 켜 둔 채로 PC 를 끄면 설치되지 않아요. 다음에 켜면 카드가 다시 뜨니, 그때 눌러 주세요.

지금 버전 보기 · 바로 확인 — 설정(Ctrl+, 또는 팔레트의 톱니) → 정보 → 업데이트 확인.

1.0 부터는 업데이트한 뒤 처음 열 때 ‘이번에 달라진 점’을 한 번 보여 드려요. 놓쳤다면 설정 → 소식에서 다시 볼 수 있어요.

3.다시 설치하기

이럴 때만 하면 돼요: 앱이 열리지 않을 때, 업데이트 카드가 다시 시작해도 계속 뜰 때, 앱의 일부가 막혔다는 알림이 뜰 때.

  1. 백업 (권해요) — 설정 → 데이터 → 백업 내보내기… 로 플래너를 파일로 저장해요. 지금 펼친 플래너 한 권씩 저장되니, 여러 권이면 권마다 해 주세요. 앱이 열리지 않으면 건너뛰어도 돼요.
  2. 앱 닫기 — Spiralday 창을 모두 닫아요. 켜 둔 채로 설치하면 설치 프로그램이 앱을 바로 닫아서, 방금 쓴 한두 글자를 잃을 수 있어요.
  3. 받아서 실행 — 이 페이지의 다운로드 단추로 새로 받은 파일을 실행해요. 먼저 지우지 않아도 돼요. 쓰던 Spiralday 위에 그대로 설치돼요.
  4. 확인 — 앱이 열리면 플래너가 그대로인지 봐요.

예전에 받아 둔 Spiralday-Setup.exe 는 쓰지 마세요. 설치 프로그램은 버전을 따지지 않아서, 예전 파일로 설치하면 예전 버전으로 돌아가요. 늘 이 페이지에서 새로 받아 주세요.

4.자주 묻는 질문

‘Windows의 PC 보호’ 창이 떠요

Windows 의 SmartScreen 이에요. 새로 나온 파일은 받은 사람이 충분히 쌓일 때까지 이 창을 띄워요. 회사 서명을 넣은 파일도 처음에는 그래요.

추가 정보를 누르면 게시자가 보여요. LeanAgileHungry . INC 이면 실행을 눌러 주세요. 게시자가 ‘알 수 없음’이거나 다른 이름이면 실행하지 말고, 이 페이지에서 다시 받아 주세요.

Edge 가 ‘일반적으로 다운로드되지 않습니다’라고 해요

새로 나온 파일을 받은 사람이 아직 많지 않으면 Edge 가 띄우는 경고예요. 회사 서명과는 따로라서 1.0 에서도 뜰 수 있어요. 받는 사람이 쌓이면 줄어들어요.

다운로드 목록에서 파일 옆의 … → 유지 → 더 보기 → 그래도 계속을 누르면 받아져요. (Edge 버전에 따라 ‘더 보기’가 ‘자세히 표시’로 보이는 등 글자가 조금 다를 수 있어요.)

‘스마트 앱 컨트롤’이 막았다고 나와요 · 설치가 아예 안 돼요

Windows 11 의 스마트 앱 컨트롤은 서명이 없는 파일을 막아요. 0.9 버전 설치 파일 안에는 서명이 빠진 파일이 몇 개 있어서, 이 기능이 켜진 PC 에서 설치가 막힐 수 있었어요. 1.0 부터는 설치 파일 안의 모든 파일에 서명해서, 막히지 않도록 고쳤어요.

  1. 예전에 받아 둔 설치 파일은 지워요.
  2. 이 페이지의 다운로드 단추로 새로 받아 설치해요.

그래도 막히면 스마트 앱 컨트롤을 끄지 말고 저희에게 알려 주세요. 이 기능은 앱 하나만 허락하는 방법이 없어서, 끄면 PC 전체의 보호가 꺼져요. 켜져 있는지는 Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 볼 수 있어요.

업데이트 · 다시 설치하면 기록은 그대로인가요?

네. 플래너는 앱과 따로 %APPDATA%\Spiralday 폴더에 저장돼요. 업데이트도, 다시 설치도, 앱 제거도 이 폴더를 지우지 않아요.

동기화를 켜 두었어도 같은 PC · 같은 Windows 계정이면 그대로 이어져요.

백업은 어떻게 하나요?
  • 한 권씩 — 설정 → 데이터 → 백업 내보내기… 로 지금 펼친 플래너를 파일 하나로 저장해요. 다른 PC 나 Mac 의 Spiralday 에서도 백업 가져오기… 로 열 수 있어요.
  • 통째로 — 앱을 닫고, 설정 → 데이터 → 탐색기에서 보기로 열리는 Spiralday 폴더를 USB 같은 곳에 복사해 둬요.
  • 자동 백업 — 앱을 켤 때 하루 한 번 모든 플래너를 복사해 최근 14일치를 남겨요. 설정 → 데이터 → 자동 백업에서 그날의 플래너를 새 플래너로 가져올 수 있어요.
지금 버전은 어디서 보나요?

설정(Ctrl+, 또는 팔레트의 톱니) → 정보. 같은 화면의 업데이트 확인으로 바로 확인할 수 있어요.

다른 PC 로 옮기고 싶어요

지금 PC 에서 백업 내보내기… 한 파일을 새 PC 의 Spiralday 에서 백업 가져오기… 로 열어요. 동기화를 쓰고 있다면 새 PC 에서 설정 → 동기화 → ‘다른 기기에 합류하기’를 하면 저절로 맞춰져요.

데이터 폴더를 통째로 다른 PC 에 옮기면 플래너는 그대로지만, 동기화 연결은 그 PC 에서 읽을 수 없어요. 이때는 복구 코드나 ‘기기 추가’로 다시 연결해 주세요.

회사 · 학교 PC 에서 설치가 안 돼요

관리하는 곳에서 정한 규칙으로 설치가 막힐 수 있어요. PC 를 관리하시는 분께 물어봐 주세요.

Windows 10 에서도 되나요?

네, Windows 10 · 11 (64비트)에서 돼요. 스마트 앱 컨트롤은 Windows 11 에만 있어요.

앱을 지우고 싶어요

Windows 설정 → 앱 → 설치된 앱(Windows 10 은 앱 및 기능) → Spiralday → 제거. 플래너 폴더(%APPDATA%\Spiralday)는 남겨 둬요. 기록까지 모두 지우려면 이 폴더도 직접 지워 주세요. 동기화를 켰다면 먼저 Spiralday 의 설정 → 동기화 → ‘이 컴퓨터에서 끄기’를 하고 지워요.

받아 두었던 업데이트 설치 파일(약 110MB)은 %LOCALAPPDATA%\spiralday-web-updater 에 남아 있을 수 있어요. 이 폴더도 지워도 돼요.
