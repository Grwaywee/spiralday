개인정보 처리방침

주식회사 린에자일헝그리(이하 ‘회사’)는 Spiralday 를 만들고 운영해요. Spiralday 가 어떤 정보를 왜 처리하는지 여기에 적어 둡니다.

시행일: 2026년 9월 29일 · 개정: 2026년 10월 3일 (Spiralday Sync 추가)

  • 플래너 기록은 내 기기에 — 회사로 보내지 않아요. 동기화(선택)를 켜면 회사도 읽을 수 없게 암호화한 사본만 동기화 서버에 둬요
  • 익명 사용 통계 — 하루 한 번 앱 버전 · 운영체제와 버전 · 칩 종류 · 언어 · 무작위 설치 번호만. 설정에서 끌 수 있어요
  • 계정 · 광고 없음 — 로그인도, 광고도 없어요

1.처리하는 정보와 목적

가. 익명 사용 통계

Mac 앱 1.0.2, Windows 앱 0.9.0 부터, 앱을 쓰는 날 하루 한 번 아래 항목을 회사 서버로 보내요.

항목내용
설치 번호앱을 처음 켤 때 만드는 무작위 번호예요. 기기 일련번호 같은 하드웨어 정보로 만들지 않아요.
앱 버전 · 빌드 번호예: 1.0.2 · 3
운영체제Mac 또는 Windows (Windows 앱만 보내요. 없으면 Mac 으로 봐요)
운영체제 버전예: macOS 15.6.1, Windows 10.0.22631
칩 종류Apple Silicon · ARM(arm64) 또는 Intel · AMD(x86_64)
언어컴퓨터의 첫 번째 선호 언어 코드. 예: ko

목적: 몇 명이 쓰는지, 어떤 운영체제 · 버전 · 칩에서 쓰는지(호환성)를 알기 위해서예요. 이름 · 이메일 · 플래너 내용은 들어 있지 않아요.

Mac 은 설정 → 데이터, Windows 는 설정 → 익명 사용 통계에서 ‘익명 사용 통계 보내기’를 끄면 그때부터 보내지 않아요.

나. 문의 메일

contact@leanagilehungry.com 으로 메일을 보내면 보낸 분의 이메일 주소와 메일 내용을 받게 돼요. 답장하고 문의를 처리하는 데만 써요.

다. 플래너 기록은 수집하지 않아요

할 일, 타임테이블, 메모, 형광펜, D-day 같은 기록은 내 기기에 저장돼요 (Mac: ~/Library/Application Support/Spiralday, Windows: %APPDATA%\Spiralday). 회사로 보내지 않고, 회사는 볼 수 없어요. 동기화를 켜도 마찬가지예요 (아래 라).

라. Spiralday Sync (내 기기끼리 동기화 — 켤 때만)

동기화는 기본으로 꺼져 있고, 앱의 설정 → 동기화에서 켤 때만 써요. 켜지 않으면 아래 정보는 아무것도 만들거나 보내지 않아요. 계정이 없어서 이름 · 이메일 · 전화번호를 받지 않아요.

켜면 플래너 기록을 내 기기에서 종단간 암호화한 뒤 동기화 서버(sync.spiralday.com)로 보내요. 암호를 푸는 열쇠는 내 기기에만 있어서 서버도, 회사도 내용을 읽을 수 없어요.

서버가 두는 것내용
암호화한 기록플래너 내용 · 플래너 이름 · 날짜 · 기기 이름은 모두 암호문이에요. 기록마다 무작위로 보이는 번호(불투명 id)와 순번만 붙어요.
기록의 크기와 쓴 때암호문의 바이트 수, 서버에 올린 시각, 어느 기기가 올렸는지
기기 목록그룹의 기기 수, 기기 종류(Mac · Windows · iPhone · iPad 등), 들어온 때 · 마지막으로 접속한 때, 기기를 알아보는 토큰의 해시 값(토큰 그대로는 두지 않아요)
복구 보관함복구 코드로만 풀리는 암호화한 그룹 열쇠 (복구 코드는 서버에 보내지 않아요)
요청 제한용 IP 값남용을 막으려고 IP 주소를 HMAC-SHA256 으로 바꾼 값만 요청 수를 세는 동안(최대 24시간) 두고 지워요. IP 주소 그대로는 저장하지 않아요.

목적: 내 기기들의 플래너를 같게 맞추고, 잘못 고친 하루 · 한 주를 이전 버전으로 되돌리고, 기기를 모두 잃었을 때 복구 코드로 되살리기 위해서예요. 서버는 내용을 읽지 못하므로 분석 · 광고에 쓰지 않아요.

2.보관 기간

  • 익명 사용 통계: 수집한 날로부터 2년이 지나면 파기해요.
  • 문의 메일: 처리가 끝난 뒤 1년 안에 지워요.
  • 동기화: 그룹을 지우면(설정 → 동기화 → 그룹 지우기) 서버의 사본을 바로 지워요. 그룹을 13개월(396일) 동안 쓰지 않으면 저절로 지워요. 덮어쓴 이전 버전은 덮인 때부터 30일, 그룹에서 뺀 기기의 표시는 30일 뒤에 지워요. 요청 제한용 IP 값은 최대 24시간 뒤에 지워요.

3.제3자 제공

회사는 이 정보를 제3자에게 제공하지 않아요.

4.처리 장소와 외부 서비스

  • 익명 사용 통계는 회사가 운영하는 서버에 저장돼요. 서버는 Amazon Web Services(AWS) 서울 리전(ap-northeast-2)에 있어요.
  • 앱 다운로드와 업데이트 확인은 GitHub(GitHub Releases · GitHub Pages)를 거쳐요. 앱은 하루 한 번 새 버전이 있는지 확인하고, 있으면 GitHub Releases 에서 받아요. 이 과정에는 GitHub 개인정보 처리방침이 적용돼요.
  • 이 웹사이트(spiralday.com)도 GitHub Pages 에서 열리고, 손글씨 글꼴은 Google Fonts 에서, GitHub 별 개수는 GitHub API 에서 불러와요.
  • 동기화 서버는 Cloudflare, Inc. 의 Workers · Durable Objects 에서 돌아요 (저장 위치는 아시아 · 태평양 지역으로 지정). 동기화를 켠 기기가 서버와 주고받을 때 위 1-라의 정보가 네트워크로 Cloudflare 의 서버(미국 회사, 처리하는 데이터센터는 여러 나라에 있어요)로 가고, 2의 기간 동안 보관돼요. 이 과정에는 Cloudflare 개인정보 처리방침이 적용돼요. 동기화를 켜지 않으면 아무것도 가지 않아요.

5.접속 기록

익명 사용 통계에는 IP 주소를 저장하지 않아요. 다만 서버를 운영하면서 보안과 장애 대응을 위해 접속 기록(IP 주소, 접속 시각 등)이 서버에 일시적으로 남을 수 있어요.

동기화 서버의 운영 기록에는 요청 주소를 남기지 않고, 오류 · 사용량을 살피는 데 필요한 사건(예: 그룹을 만듦)만 남겨요. 플래너 내용은 암호문이라 기록에 남을 수 없어요.

6.이용자의 권리

  • 끄기 — Mac 은 설정 → 데이터, Windows 는 설정 → 익명 사용 통계에서 ‘익명 사용 통계 보내기’를 끄면 돼요.
  • 지우기 — 같은 화면에 보이는 설치 번호를 contact@leanagilehungry.com 으로 보내 주시면 그 번호로 쌓인 기록을 지워요.
  • 동기화 끄고 지우기 — 설정 → 동기화에서 ‘이 기기에서 끄기’로 그 기기만 빠지고, ‘그룹 지우기’로 서버의 사본을 바로 모두 지워요. 계정이 없어서 회사는 어느 그룹이 누구의 것인지 알 수 없고, 그래서 대신 지워 드릴 수 없어요. 기기를 모두 잃었으면 복구 코드로 되살린 뒤 지우거나, 13개월 뒤 저절로 지워지기를 기다려 주세요.
  • 문의 메일을 포함해 회사가 가진 내 정보의 열람 · 정정 · 삭제 · 처리 정지도 같은 주소로 요청할 수 있어요.
