1.처리하는 정보와 목적

가. 익명 사용 통계

Mac 앱 1.0.2, Windows 앱 0.9.0, Android 앱 1.0.0, iPhone · iPad 앱 1.0.0 부터, 앱을 쓰는 날 하루 한 번 아래 항목을 회사 서버로 보내요. 개발용 빌드는 보내지 않고, Android 앱은 Google Play 가 출시 전에 앱을 자동으로 실행해 보는 시험 기기(출시 전 보고서의 Firebase Test Lab 기기)에서도 보내지 않아요.

나. Spiralday Sync (동기화를 켰을 때만)

Spiralday Sync 는 내 기기들 사이에서 플래너를 맞추는 기능이에요. 처음에는 꺼져 있고, 켜기 전까지는 아무것도 보내지 않아요.

플래너 내용은 종단간 암호화돼요. 각 기기가 플래너 기록과 기기 이름을 그룹 키로 잠근 뒤 보내고(XChaCha20-Poly1305), 그룹 키는 내 기기의 보안 저장소(예: iPhone · iPad 의 키체인, Android 의 키스토어, Windows 의 DPAPI)에만 있어요. 그래서 회사도, 서버를 운영하는 Cloudflare 도 할 일 · 메모 · 날짜 · 플래너 이름 · 기기 이름을 읽을 수 없어요.

서버가 갖는 것은 아래뿐이에요.

항목내용
암호화된 플래너 사본기록마다 지금 버전 하나와 덮어쓴 이전 버전(30일). 기록 번호도 내용을 알 수 없게 만든 값이에요.
무작위 그룹 · 기기 번호동기화를 켤 때 서버가 정하는 무작위 번호예요. 이름 · 이메일 · 전화번호와 이어지지 않아요.
기기 정보암호화된 기기 이름, 기기 종류(Mac · Windows · Android · iPhone · iPad), 기기 인증 토큰의 해시(SHA-256), 그룹에 들어온 때, 마지막 접속 시각(10분 단위)
순번 · 시각 · 크기쓸 때마다 하나씩 오르는 순번, 쓴 시각과 쓴 기기 번호, 암호문의 크기, 그룹의 사용량과 마지막 사용 시각(1시간 단위)
기기 연결 중의 값연결 코드의 해시와 그룹 키를 감싼 값. 감싼 키는 새 기기가 받아 가거나 연결을 취소 · 거절하거나 시간이 지나면 바로 지우고, 연결 기록도 1시간 안에 지워요.
복구 보관함복구 코드로 감싼 그룹 키와 확인값의 해시. 복구 코드 자체는 서버로 보내지 않아요.
IP 주소저장하지 않아요. 남용을 막는 요청 제한에 IP 를 비밀 키로 바꾼 값(HMAC-SHA256)만 그 제한 시간 동안(길어야 24시간) 세고 지워요.

같은 그룹의 다른 기기가 함께 열려 있으면 실시간 쓰기로 맞춰요. 입력하는 동안 바뀐 부분을 플래너 기록처럼 그룹 키로 잠근 조각이 서버를 거쳐 그 기기로 바로 전달돼요. 서버는 이 조각을 저장하지 않고 넘기기만 하고(그래서 위 표에 없어요), 잠겨 있어서 내용을 볼 수 없어요. 다만 전달하는 동안 어느 기기가 언제 입력하는지(입력하는 시각과 간격)와 조각의 대략적인 크기(256바이트 단위)는 서버를 거쳐요. 이 값도 저장하거나 기록으로 남기지 않아요.

목적: 내 기기들 사이에 플래너를 맞추고, 서버를 남용하지 못하게 막기 위해서예요. 요청 주소가 남는 서버 호출 기록은 끄고 운영해요.

라. 플래너 기록은 내 기기에

할 일, 타임테이블, 메모, 형광펜, D-day 같은 기록은 내 기기에 저장돼요. 동기화를 켜지 않으면 기기 밖으로 나가지 않고, 켜도 회사는 내용을 볼 수 없어요(위 나).

마. 기기 권한

iPhone · iPad 앱은 동기화 연결 QR 코드를 찍을 때만 카메라를, 플래너 쪽을 이미지로 저장할 때만 사진 보관함(추가만)을 써요. 찍은 화면과 이미지는 기기 밖으로 보내지 않아요. Android 앱은 인터넷 · 진동 · 네트워크 상태(연결이 돌아오면 동기화를 다시 잇기 위해)를 쓰고, 카메라는 동기화 연결 QR 코드를 찍을 때만 물어서 써요. 카메라 화면은 기기 안에서 바로 읽고(Google ML Kit, 아래 4) 저장하거나 보내지 않아요. 카메라를 허용하지 않아도 8자리 코드로 똑같이 연결할 수 있어요.

2.보관 기간

  • 익명 사용 통계: 수집한 날로부터 2년이 지나면 파기해요.
  • Spiralday Sync: 동기화하는 동안 보관해요. 덮어쓴 이전 버전은 30일 뒤 지워요. 설정 → 동기화의 ‘그룹 지우기’를 누르면 서버의 사본을 바로 지우고, 그룹의 어느 기기도 13개월(396일) 동안 접속하지 않으면 저절로 지워요. 마지막 기기가 동기화를 꺼도 복구 코드로 돌아올 수 있게 그 13개월 동안은 남아 있으니, 남기고 싶지 않으면 ‘그룹 지우기’를 써 주세요.
  • 실시간 쓰기 조각: 저장하지 않아요. 다른 기기로 넘기는 동안만 서버의 메모리를 지나가요.
  • 그룹에서 뺀 기기의 정보는 바로 지워요. 그 기기에 ‘그룹에서 빠졌어요’ 라고 알려 주려고 인증 토큰의 해시만 30일 동안 남겨요.
  • 요청 제한에 쓰는 IP 의 HMAC 값: 길어야 24시간.
  • 문의 메일 · Threads DM: 처리가 끝난 뒤 1년 안에 회사가 가진 기록을 지워요. Threads 안의 대화는 회사가 지울 수 있는 만큼 지우고, 나머지는 Meta 의 방침을 따라요.

3.제3자 제공

회사는 이 정보를 제3자에게 제공하지 않아요. Spiralday Sync 서버를 돌리는 Cloudflare 와 익명 사용 통계 서버가 있는 Amazon Web Services(AWS)는 회사가 처리를 맡긴 곳이에요(아래 4).

다만 Android 앱에서 동기화 연결 QR 코드를 찍으면, 앱에 들어 있는 Google ML Kit 가 자기 동작에 관한 진단 정보(기기 · 앱 정보, 설치별 식별자, 언어 · 국가 · 시간대, 통신사 · 네트워크 종류, 이벤트 코드 등)를 Google LLC 로 직접 보내요. 회사는 이 정보를 받지 않고, Google 이 자기 정책에 따라 처리해요. 미국으로 가는 정보라 보내는 항목을 모두 아래 4 의 국외 이전 ② 에 적었어요. QR 코드 대신 8자리 코드로 연결하면 이 진단 정보는 보내지 않아요.

그리고 Android 에서는 글을 쓰는 칸이 화면에 나타날 때마다, 앱 화면을 그리는 Android 시스템 구성요소(Android System WebView)가 자동 완성을 위해 Google 에 물어봐요. 이때 보내는 것은 WebView 버전과 그 칸의 구조를 나타내는 값(해시)이에요. 쓴 글은 들어 있지 않고, 회사는 이 값을 받지 않아요. 앱이 아니라 WebView 가 하는 일이라 앱 안에는 이것을 끄는 설정이 없어요.

4.처리 장소와 외부 서비스

  • 익명 사용 통계는 회사가 운영하는 서버에 저장돼요. 서버는 Amazon Web Services(AWS) 서울 리전(ap-northeast-2)에 있어요.
  • Spiralday Sync 서버(sync.spiralday.com)는 Cloudflare, Inc. 의 Workers · Durable Objects 에서 돌아요 (아래 국외 이전).
  • 앱을 받고 업데이트하는 곳: Mac · Windows 앱은 GitHub(GitHub Releases · GitHub Pages)에서 받고, 앱이 하루 한 번 새 버전이 있는지 확인해요(GitHub 개인정보 처리방침). Android 앱은 Google Play, iPhone · iPad 앱은 App Store 에서 받고 업데이트해요 — 이때는 Google · Apple 의 개인정보 처리방침이 적용돼요.
  • Android 앱이 QR 코드를 읽을 때는 Google 의 ML Kit(기기 안에서 도는 바코드 인식)를 써요. 카메라 화면은 기기 밖으로 나가지 않지만, ML Kit 는 자기 동작에 관한 진단 · 사용 통계(기기 · 앱 정보, 설치별 식별자, 언어 · 국가 · 시간대, 통신사 · 네트워크 종류, 성능, API 설정, 이벤트 · 오류 코드 등)를 Google 로 보내요(HTTPS). 보내는 항목 전체는 아래 국외 이전 ② 에 적었어요. 설치별 식별자는 앱을 설치할 때마다 새로 정해지는 번호로, 기기나 사용자를 가리키지 않아요. 앱의 ‘익명 사용 통계 보내기’와는 따로라서, 통계를 꺼도 QR 코드를 찍으면 보내요. 이 정보는 Google 이 ML Kit 데이터 공개와 Google 개인정보처리방침에 따라 처리하고, 회사는 받지 않아요.
  • 이 웹사이트(spiralday.com)도 GitHub Pages 에서 열리고, 손글씨 글꼴은 Google Fonts 에서, GitHub 별 개수는 GitHub API 에서 불러와요.
